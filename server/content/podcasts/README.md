# ملفات البودكاست الصوتية (اختياري)

المكتبة الجاهزة تشغّل الحلقتين من Google Drive افتراضياً، وهذا يعمل لكل
الطلاب لأن الملفين مشاركان للعموم.

لاستضافة الصوت على خادم الموقع بدل درايف (تشغيل أسرع ومشغّل أصلي)، ضع
الملفين هنا بهذين الاسمين بالضبط:

- `pr13-public-relations-podcast.m4a`
- `rp535-radio-programs-podcast.m4a`

سيلتقطهما الخادم تلقائياً ويقدّمهما على
`/api/library/podcasts/:slug/audio` بلا أي تعديل في الكود.

بديل ثالث: ضبط متغيري البيئة `PODCAST_PR13_URL` و `PODCAST_RP535_URL`
برابط مباشر لملف صوتي.

ترتيب الأفضلية: ملف محلي ← متغير بيئة ← مشغّل Google Drive.
